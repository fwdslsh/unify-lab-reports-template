# Provenance

The reusable layout, styles, source-inventory navigation, search, retention,
dashboard rendering and atomic publisher were extracted from the fwdslsh lab's
reports implementation with the project owner's authorization. This repository
has a new Git history and contains no private lab reports or observations.

The green forward-slash visual system derives from the fwdslsh website's style:
https://github.com/fwdslsh/website, copyright fwdslsh contributors, CC-BY-4.0.
The adapted `site/styles.css` and `site/_layout.html` retain that license;
changes include configurable generic branding and lab dashboard presentation.
The full attribution license is included in `LICENSES/CC-BY-4.0.txt`.
The layout and mobile interaction patterns are retained; sample branding is
generic and can be changed using configuration. No private lab identities,
addresses, deploy credentials or original content archives are distributed.

Unify is an external dependency from https://github.com/fwdslsh/unify. Its
checked-in source license is CC-BY-4.0; its code is not bundled into this npm
template payload. Dependency and asset licenses retain their own terms.

Other template code and examples are MIT licensed; see LICENSE. Distribution
includes both licenses, reflected by the package's MIT AND CC-BY-4.0 expression.
